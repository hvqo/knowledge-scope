# 浏览器产品冒烟清单

这是一份发布前的手工检查表。每次检查使用同一个本地浏览器会话、一个非敏感 PDF、一个
隔离的知识库和一个已注册的业务数据源；不要把检查结果当作检索或 ChatBI 质量基准。

## 主流程

- [ ] `/knowledge-bases` 可以创建知识库，空列表、加载失败和重试状态可用。
- [ ] 上传 PDF 后，文档列表显示安全的中文状态；删除前有确认，删除后列表刷新。
- [ ] `/chat` 可以选择知识库、发送问题、看到流式回答、完成状态和真实来源卡片。
- [ ] 点击 citation marker 只聚焦对应来源；页码、block 和资产信息来自服务端字段。
- [ ] `/analysis` 的数据源列表只允许选择可用数据源；空列表、停用数据源、失败和重试提示清楚。
- [ ] 简单分析结果的列顺序、行数、截断提示和错误状态与接口一致。
- [ ] `/reports` 可以创建报告；报告列表的知识库/数据源上下文不会显示内部 ID。
- [ ] `/reports/:id` 的章节编辑、预览、保存、来源插入和来源移除行为可解释。
- [ ] 移除报告来源、删除章节、删除知识库等破坏性操作都会先要求确认。
- [ ] 修改正文后切换章节、切换报告或离开页面：保存成功才继续，失败则停留并保留草稿。
- [ ] RAG、ChatBI、AI 生成或导出进行中切换报告；迟到响应不会改变新报告。
- [ ] AI 大纲/章节/改写/扩写/精简先进入预览，接受后仍需显式保存。
- [ ] DOCX 和 PDF 导出成功；空报告、超限报告和后端 400/409/422 错误显示受控中文提示。

## ChatBI 资格状态

### CLARIFY

- [ ] 在 `/analysis` 提交一个相对于演示 schema 含义不明确的分析问题（没有确定指标、维度或筛选范围），确认使用现有 CLARIFY 路径。
- [ ] 页面显示中文澄清提示；不显示成功结果表格或图表。
- [ ] 没有结果或来源可以插入报告；页面不显示原始 SQL、provider 内容、内部策略或调试信息。
- [ ] 补充或改写问题后，可以继续发起正常分析。

### REFUSE

- [ ] 在 `/analysis` 提交一个被现有 ChatBI 安全/资格策略拒绝的问题（例如要求修改、删除或写入数据），确认使用现有 REFUSE 路径。
- [ ] 页面显示安全的中文拒绝提示；不显示 SQL 执行结果、表格或图表。
- [ ] 被拒绝的内容不能插入报告；页面不显示内部策略、provider 内容或调试信息。

## 失败路径

- [ ] 断开 API 后，页面显示可理解的错误和重试入口，不显示堆栈、DSN、凭据或原始 provider 内容。
- [ ] 停用数据源的 ChatBI 409 显示“当前数据源不可用或已停用”，不显示重复内容提示。
- [ ] RAG/ChatBI/AI/导出被取消或网络失败后，加载状态会结束，重新操作仍可用。
- [ ] 刷新或关闭有未保存报告草稿的页面时出现浏览器标准离开提示；不会尝试异步保存。

## 视口与安全

- [ ] 在约 1440px 宽度下，侧栏、报告三栏和来源卡片不遮挡主要操作。
- [ ] 缩窄到移动宽度后，页面可滚动，按钮和错误信息仍可见。
- [ ] 页面不会把 `v-html`、原始 SQL、内部请求 ID、凭据或未经服务端确认的 URL 当作用户内容渲染。
- [ ] 浏览器开发者工具中没有看到向外部 provider 发送的请求；此清单不包含 DEV/TEST 基准运行。
