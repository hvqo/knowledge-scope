# 知识图谱可视化

知识图谱页面把 Neo4j 中已有证据支撑的实体与关系直接展示在网页上，用于理解一个知识库抽取出的概念结构。它是一条只读路径：不新增图写入、不触发抽取或实体链接，也不会在缺少图谱数据时生成占位内容。

## 数据边界

页面只读本地图谱（A3.1 实体、关系与证据）和规范实体（A3.3 `CanonicalEntity`）中已经持久化的内容。接口只返回渲染和追溯所需字段：实体名称、类型、别名、所属文档、可见边数量、证据数量、规范实体标识，以及边的类型、种类与所属文档。Neo4j 内部属性、provider trace、prompt 和 token 信息不会进入响应。

实体与关系沿用检索分支的同一条约束：只有当前文档仍存在对应证据时才会出现。这样画布上的每个节点和每条边都能追溯到某个文档页码，删除文档后其图状态不会残留在视图里。

自引用关系不参与画布：它们无法渲染成有意义的边，也会干扰度中心性排序。

## 视图范围

实体和关系都是文档内局部的，跨文档的联系来自 A3.3 的规范实体归并。因此页面按两种范围取数：

- **文档范围（默认）**：显示该文档内部按度数排名靠前的实体及其关系，这是一个连通的稠密子图。
- **全部文档**：显示整个知识库中按度数排名靠前的实体。此时只有在展示集合内部存在关系或归并边时才会出现连线，所以这个视图通常更稀疏；页面会明确提示改为选择单个文档。

两种范围都先选出节点，再只取这些节点之间的边，所以画布永远不会收到指向画布外节点的悬空边。节点的 `degree` 只统计当前视图中可见的边，实体详情面板里的相邻实体数量才是该实体在图里的完整邻居数。

归并边（`kind = canonical_bridge`）表示两个本地实体被归并到同一个规范实体，用虚线渲染并且不带箭头；文档范围内不取归并边，因为它本身是文档内的局部视图。

## API

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/v1/knowledge-bases/{knowledge_base_id}/graph` | 一个有界子图：节点、边、类型选项与截断标记 |
| GET | `/api/v1/knowledge-bases/{knowledge_base_id}/graph/entities/{entity_id}` | 单个实体的别名、规范归并、来源证据与相邻实体 |

概览接口接受 `search`（名称或别名的大小写无关子串匹配）、`entity_type`（精确类型过滤）、`document_id`（文档范围）和 `limit`（1–500，默认 200）。无筛选时按可见度数降序取前 `limit` 个实体；有筛选时先在 bounded 扫描内匹配，再按名称稳定排序。搜索会扩大实体扫描范围以保证命中率；响应中的 `truncated` 说明结果已被裁剪。

实体详情接口接受 `max_neighbors`（1–100，默认 20），返回实体的规范归并实体、来源证据（文档与页码）和相邻实体（关系类型、方向与证据页码）。节点不存在或标识格式不正确时返回 404；Neo4j 不可用时返回 503，前端统一展示为“服务暂时不可用”。

两个接口都只依赖 Neo4j，不校验知识库在 PostgreSQL 中是否存在，因为图谱数据本身已按知识库隔离。

## 前端页面

`/knowledge-graph` 先选择知识库，再展示画布与详情面板。URL 通过 `?kb=<id>` 记住当前知识库，知识库详情页也提供直达入口。文档列表复用现有文档接口；默认选中第一个文档，可随时切回“全部文档”。

详情面板浮动在画布右上方，画布因此始终占据整行宽度，在窄窗口下也能看清节点与标签。

### 画布布局

画布是自绘 SVG，布局是确定性的「按连通分量分团」计算，不引入图可视化依赖：

1. 先用连通分量把实体分成若干社区；
2. 每个社区在**各自的椭圆边界内**做一次斥力/引力迭代，再等比放大填满所属方框——边界既避免社区塌缩成一个点，也避免链状社区展成一条细线；
3. 社区方框按面积求解尺寸后按行打包，整体居中；只有一个社区时（文档视图的常见情况）直接铺满整块画布。

方框尺寸由社区规模推出，社区之间的空隙与社区内部的节点间距保持同一量级，因此不同社区在画布上是大小相当、边界清楚的若干组，而不是一圈小圆点。同一份数据每次渲染结果一致，拖动节点只是局部微调。

### 交互

- **标签**：默认只显示中心实体、选中实体的邻居和度数较高的实体；标签沿远离聚焦点的方向排布以避免堆叠，“全部标签”可展开全部名称。
- **聚焦**：点击节点查看证据，双击节点或点击“聚焦选中”把该实体与相邻实体放大到视野中央（取景会避开右侧详情面板）；“适应画布”回到全览，另有缩放与重置。
- **关系标签**：只在聚焦实体的边不多于 4 条时显示，避免中心实体周围堆满重复文字；完整关系类型始终能在详情面板的相邻实体列表里看到。
- **隐藏未连接**：搜索结果里常有大量没有可见关系的实体，可一键隐藏，仅在有此类实体时出现。
- 拖动节点、背景平移、滚轮缩放均可用；选中或悬停时其余节点淡化，只保留一跳邻居。

详情面板展示所选实体的类型、别名、已归并的规范实体、来源证据（文档名与页码）和相邻实体列表。相邻实体是可点击按钮，因此不依赖鼠标也能沿图逐步浏览。搜索与类型筛选都有防抖和“清空筛选”入口；视图被裁剪时会明确提示当前只显示连接最紧密的部分。

知识库为空、图谱为空和服务不可用是三种显式状态：空知识库引导去创建，空图谱说明图谱会随文档整理逐步生成，服务不可用提供重试。
